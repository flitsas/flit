# HU #11177

[BACKEND] – Representantes legales – Marcar la compañía principal en el detalle

## Description

<p><strong>Como</strong> administrador de una compañía gestora,<br><strong>quiero</strong> que el sistema indique cuál de las compañías de un representante es la principal,<br><strong>para</strong> que la interfaz pueda distinguirla sin depender de convenciones frágiles. </p>

## Acceptance Criteria

<h3>AC1 — Marcar explícitamente la compañía principal </h3><pre>Given un representante con varias compañías asociadas
When se consulta su detalle o el listado
Then exactamente una de sus compañías viene marcada como principal</pre><h3>AC2 — Orden estable entre consultas </h3><pre>Given un representante con varias compañías asociadas
When se consulta su detalle dos veces seguidas
Then las compañías se devuelven en el mismo orden y la principal aparece primero</pre><h3>AC3 — Representante con una sola compañía </h3><pre>Given un representante con una única compañía asociada
When se consulta su detalle
Then esa compañía viene marcada como principal</pre><p><em>Notas técnicas:</em> la marca se expone como campo propio del contrato; no debe inferirse de la columna denormalizada de compañía representada, que quedó deprecada y admite nulos. </p>
