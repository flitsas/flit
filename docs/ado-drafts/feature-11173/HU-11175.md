# HU #11175

[BACKEND] – Representantes legales – Seleccionar la firma del baúl al guardar el representante

## Description

<p><strong>Como</strong> administrador de una compañía gestora,<br><strong>quiero</strong> elegir cuál de las firmas vigentes del baúl se asocia a un representante legal,<br><strong>para</strong> que el trámite firme con la firma correcta cuando la persona tiene más de una registrada. </p>

## Acceptance Criteria

<h3>AC1 — Consultar el baúl filtrando por el documento del representante </h3><pre>Given una compañía con firmas de varias personas en el baúl
When se consulta el baúl indicando el tipo y el número de documento de un representante
Then la respuesta solo incluye las firmas de esa persona</pre><h3>AC2 — Devolver únicamente las firmas vigentes </h3><pre>Given una persona con una firma vigente y otra vencida en el baúl
When se consulta el baúl pidiendo solo las vigentes
Then la respuesta incluye la firma vigente y excluye la vencida</pre><h3>AC3 — Guardar la firma elegida explícitamente </h3><pre>Given un representante y una firma vigente de esa misma persona
When se guarda el representante indicando el identificador de esa firma
Then el representante queda asociado a la firma elegida y no a la que resolvería el sistema</pre><h3>AC4 — Rechazar una firma que no corresponde </h3><pre>Given un representante y una firma de OTRA persona, o vencida, o de otra compañía
When se guarda el representante indicando esa firma
Then la operación se rechaza con un error de validación y el representante no queda asociado a ella</pre><h3>AC5 — Conservar la resolución automática </h3><pre>Given un representante que se guarda sin indicar ninguna firma
When se completa el guardado
Then el sistema resuelve la firma o la identidad como lo hace hoy, sin cambios de comportamiento</pre><p><em>Notas técnicas:</em> filtros nuevos en el listado del baúl; el input de escritura del representante acepta el identificador de firma y lo valida contra tenencia, documento y vigencia antes de persistirlo. </p>
